0. 基准尺寸表

  一切边距相关尺寸都需要使用 view/common/getSize.js获取（与 getColor 同级）
  公式 getSize(k) = (2 × 2k) / 10 rem，即 0.4k rem（4k px），k 取任意数
  内部以 0.2rem 为最小单位计算，整数 k 恒输出 0.4 的倍数（对齐业界 4px 生态）
  纪律：
  行内 style 禁止出现裸 px/rem 字面量，必须走 getSize(k)
  一档一用途全站唯一；要改值只改这张表，不改调用处；永不造代码别名，中文档名仅查表用
  非长度量（动效时长、颜色、透明度、对比度）不归 getSize，归常量条款

  间距 / 内边距：
  （rem 列即 getSize 返回的数值，使用时自行拼单位如 "#{getSize(8)}rem"；px 列仅为根字号 10px 下的换算参考）
  零距 getSize(0) 0rem 0px 显式无间距
  迷你间距 getSize(1/2) 0.2rem 2px 发丝级微调（常驻分数档）
  小间距 getSize(1) 0.4rem 4px 图标贴文字、行内微调
  基本间距 getSize(2) 0.8rem 8px 组件默认内边距
  中间距 getSize(3) 1.2rem 12px 小元素内边距、块内堆叠
  大间距 getSize(4) 1.6rem 16px 卡片/面板内边距
  区块间距 getSize(6) 2.4rem 24px 模块之间
  页面留白 getSize(8) 3.2rem 32px 页面级四周

  控件高（高度不写死，靠内部元素计算后的总高恰等于档位值，用 padding/行高/字号组合配出来）：
  紧凑高 getSize(7) 2.8rem 28px 密集工具条
  标准高 getSize(8) 3.2rem 32px 桌面默认
  大高 getSize(10) 4rem 40px 主操作
  触控高 getSize(12) 4.8rem 48px 移动端

  字号（行高档 = 字号档 + 1，如正文 getSize(4)、行高 getSize(5)）：
  说明字号 getSize(3) 1.2rem 12px 注释、时间戳、Tag 文字
  正文字号 getSize(4) 1.6rem 16px 全局默认
  子级标题 getSize(5) 2rem 20px 分组小标题
  板块标题 getSize(6) 2.4rem 24px 侧栏一级、卡片大组
  窗口标题 getSize(7) 2.8rem 28px 页面主标题，一页至多 1-2 处
  h1 getSize(16) 6.4rem 64px 文档封面/hero 主标题
  h2 getSize(12) 4.8rem 48px 章节大标题
  h3 getSize(10) 4rem 40px 节标题
  h4 getSize(8) 3.2rem 32px 小节标题
  h5 getSize(7) 2.8rem 28px 次级小节（与窗口标题同档复用）
  h6 getSize(6) 2.4rem 24px 段落标题（与板块标题同档复用）

  圆角（全站唯一一档）：
  统一圆角 getSize(8) 3.2rem 32px，禁止混用其它半径；高 ≤64px 的元素经钳位自然成全胶囊，圆形控件可写 50%，App 图标沿用 iOS 图标比例 22%

  圆角容器嵌套（两条，按内层有无自己的圆角容器判断）：
  一、内层有自己的圆角容器（圆角套圆角）：嵌套间距取 getSize(1) 0.4rem，只为让两层轮廓分得开
  二、其余一切情况（一个容器内并列多个块、容器内直接放直角内容、两者混排）：容器到内容、块与块之间的间距，统一取 getSize(3) 1.2rem
     依据：直角角点不被圆弧裁掉的条件为 p ≥ R(1 − 1/√2) ≈ 0.293R；R=32 时临界 9.37px，0.4/0.8rem 均不足；统一取 1.2rem 既覆盖裁切安全，也避免“块有没有自己的容器”这种判断分裂
  以上两档之外不再引入其它嵌套间距；需要更大留白时，说明该处不应嵌套，应改为同级并列 + gap
  豁免：胶囊形/内容居中的控件（按钮、图标、头像）不受此限

  图标（行内图标档 = 同行字号档 + 1，线框图标需更大一档才与实心文字等重）：
  行内小图标 getSize(4) 1.6rem 16px Tag 内嵌（配说明字号 12）
  标准图标 getSize(5) 2rem 20px 底栏、列表行（配正文字号 16）
  中图标 getSize(6) 2.4rem 24px 功能按钮（展示型，不受+1约束）
  大图标 getSize(8) 3.2rem 32px 空态、大入口（展示型）

  描边（仅有的两个常驻分数档，屏幕物理位）：
  常规描边 getSize(0.25) 0.1rem 1px 颜色 rgba(0,0,0,0.15)
  焦点描边 getSize(0.5) 0.2rem 2px

  常量条款（getSize 造不出的全部例外，仅此四条）：
  动效时长 微 0.2s / 常规 0.3s / 氛围 0.5s，ease；动画必须可打断，高频交互不加动效
  阴影三档
  小卡 0 getSize(0.25) getSize(1) rgba(0,0,0,0.08)；
  浮窗 0 getSize(1) getSize(4) rgba(0,0,0,0.15)；遮罩专用
  配色纪律 getColor(色名).back/.front 配对取用，一色不两义；配色数值系人工调校，手册不规定其来源
  配色唯一例外 特殊需求下仅有背景色而无现成配对前景时，前景 = 黑/白 × 透明度（约 0x55~0x66，即33%~40%），亮底用黑、暗底用白；此算子只用于补前景色，不得用于发明新色名或制造文字层级

1. 少即是多，一切皆是Box

  Box组件是基本的样式盒子（请务必阅读Box.js），它同时提供了所有组件的基本样式规范
  Tag组件是Box组件的继承，它提供了小标签的样式

  Box的基本样式类似下面这些（不一定，这是我常用的设计样式）
  基本间距单位 建议getSize(2)=0.8rem 小间距getSize(1)=0.4rem 迷你间距getSize(1/2)=0.2rem
  圆角 参考上表
  边框线 无边框线
  背景颜色 使用getColor(颜色名).back
  文字颜色 使用getColor(颜色名).front
  【重点】必须使用颜色名的颜色，不能用里面的特定区域的颜色
  选取的颜色要同时调查3个主题下的表现，同时兼顾，否则可能会出现奇怪的效果
  -----
  宽度 不设置，默认是auto
  高度 不设置，根据内容撑开
  字号 不设置，全局继承 getSize(4)=1.6rem
  行高 默认不设置（全局默认行高/字号由 css.js 统一配置，组件层直接继承）；需显式设置时按字号档 + 1
  字重 不设置，默认

  你可以直接使用Box组件，但是有时候Box组件会过于繁重，你也可以使用普通div+遵照上面的基本样式，来叠加组件

  Box组件最常见的使用例子是作为按钮,设置 isBtn:true
  Tag组件同理，作为小按钮

  Box组件同时还作为任何东西的容器，所以你可以

  m Box,[
    #我要放置的内容
    m Box,[

    ]
  ]
  因为Box自带简单边距，所以可以快速创建出视觉上感觉还不错的东西
  但是同时我们也要注意到 两个Box叠加，边距也会叠加
  但是我设计原则里，为了最简开发，通常会忽略这个。我不会编辑额外的样式，来消除它
  但是你编写的时候务必消除这个边距，因为到最后都是要改的。常见的做法是是消除Box的margin，父容器使用gap，但是不一定

  但是很多情况下，默认的样式并不合理，我们会叠加样式
  最常见的常见就是使用flex

  m Box,
    style:
      display:"flex"
      justifyContent:"center"
      alignItems:"center"
  ,[]

  注意Tag覆盖样式使用styleExt
  m Tag,
    styleExt:
  ,[]

  Box还有其他用途，比如作为文本框

  Input = new Box()

  m Input,
    tagName:"input[type=text]"
  
  获取输入内容 Input.data.value

  或者作为开关
  m Input,
    isSwitch:true
    color:"main"
  
  获取开关状态，依然是 Input.data.value

## 前端代码风格与模块化指南

为了保持代码的高度可读性、一致性以及与系统架构的完美契合，所有 App 前端开发必须遵循以下准则：

交代：
> 1不使用任何cssClass，使用行内style，不写任何css类名。 且切记不要为style创建独立变量抽离到外部，全部嵌入编写（和m混在一起写）
2所有的json对象都要换行，不能连写{a:12,b:5}这是错误的
3mithril的第一个参数如果是div，应该简写成空字符串。
4如果一个前端事件处理函数没有被复用，应该直接写在事件里面，而不应该外置

> 减少临时变量和中间变量的使用。直接使用嵌入式写法。
例如，let a = 12 ; let b = 5; let c = a+b;console.log(c)这还是错误的写的，你应该直接console.log(a+b)

> 前端组件注意：
1 每个模块必须是合法的mitrhil函数组件，不能仿照入口点frontend.js的写法。
参数传递使用mithril的组件传参方式传递
所有尺寸单位统一使用rem 1rem 约等于 10px

> 所有的异步处理必须用try catch包裹并输出错误，不能省略任何错误的输出

> 所有的前端模块必须提供【移动端】支持（实际上只要使用系统组件默认就支持，如果自己div布局，要写好自适应app窗口尺寸的css）
【移动端事件优先使用pointer事件，并记得做好事件清理】


### 6.1 极致垂直化格式 (Vertical Formatting)
- **对象属性换行**：对象（尤其是 `style` 和配置对象）的每一个属性必须独占一行。
- **函数参数换行**：`m()` 函数的参数（tag, attrs, children）必须独占一行。
- **示例**：
  ```javascript
  m("",
    {
      style: {
        display: "flex",
        flexDirection: "column",
        padding: "#{getSize(5)}rem"
      }
    },
    [ ... ]
  )
  ```

### 6.2 零 CSS 类名原则 (Zero CSS Class)
- **严禁使用** `class` 或 `cssClass`。
- **必须使用** 行内样式 (`style`)。这确保了组件的样式完全自包含，不依赖外部 CSS 文件。
- **颜色调用**：统一使用注入的 `getColor(name).back/front` 来获取主题颜色。
其中同一个颜色下，back为背景色,front为背景色对应的文字色/前景色。
【重要】禁止发生混合使用不同颜色的背景色和前景色混搭，颜色搭配系统已经配好了。如果你的背景色是getColor("red").back，那前景色/文字色必须使用getColor("red").front，不能使用其它颜色
- **字体和字号** 不要指定任何字体，通常不需要指定字号，特殊内容可以少量指定字号

### 6.3 嵌入式写法 (Inline Expressions)
- **减少中间变量**：避免定义只使用一次的临时变量。
- **逻辑直接嵌入**：将逻辑判断、字符串拼接、数组映射直接写在 `m()` 的参数中。
- **示例**：
  - ❌ `let isDir = name.endsWith('/'); m("", isDir ? "📁" : "📄")`
  - ✅ `m("", name.endsWith('/') ? "📁" : "📄")`

### 6.4 语义化简写
- **Mithril 简写**：当第一个参数是 `div` 时，必须简写为空字符串 `m("", ...)`。
