【js/coffee 编程指南】
  以下建议供参考，非唯一标准哦
  ----
    【唯一变量名】同一个对象的传递链路统一使用唯一变量名，非必要禁止使用中间变量重命名
    【显式初始化】任何对象的传递链路必须是明确的，且只在链路的开头做初始值处理显式初始化
    【明确访问和禁止判空】不得访问未在对象创建处初始化的属性
    【避免中途添加属性】不能在非定义处中途新增对象的属性
    【唯一类型】以下类型（字符串、数组、对象、数字、布尔、集合、映射表）对象的初始值不能为null或undefined，避免复杂判空逻辑
    必须带有明确的值和类型初始化，创建后，不能够修改其类型（允许临时修改立即复原），只能在读时使用辅助函数转换
      反例： arr = []; countNum = 0 ; sayStr = "" 它们初始化就确定了类型
      反例： arr = null; count=null; say=null
      函数等无法判定默认情况的对象可以判定或使用null
      callbackFn ?= ->
    【变量名类型提示】建议使用str、arr、fn、afn(async)、num、map、set、dom等字样作为变量名尾缀做类型区分
    【变量名语义化】变量名不能使用无法理解的简写，简写必须看懂语义
    【拒绝假设，禁止兜底快速失败】任何不必要的兜底逻辑都会掩盖程序本来的报错行为，禁止假设性兜底。值应该是完全明确的。
    链路清晰，禁止出现：这个东西绝不可能是xxx，但是你做了可能是xxx的判定
    【顺序阅读】代码编写的逻辑为从上到下，从左到右，下面不能访问没有写在上面的东西
    【少即是多】杜绝无意义的额外判断，代码链路清晰、最小化创建变量
    【函数式编程】在没有继承需求时，尽量使用json纯函数对象工具库代替class
    【传参类型检查】建议使用Joi等库对函数的传参开头立即进行类型校验
    【表达式写法】让一切都是表达式，便于阅读。js可以用闭包函数实现
      value = if x
        a
      else
        b
    【嵌入式编写】同一个文件里，如果对象不被复用，那么它们应该是匿名直接嵌入的，这样便于阅读
    如果他们被复用，应该在第一个使用处存储为变量，而不是抽取到外部。例如
      mouseoverEventFn = null
      ...
      if not mouseoverEventFn
        dom.addEventListener "mouseover",mouseoverEventFn = ->
      ...
      mouseoverEventFn = dom.removeEventListener mouseover,mouseoverEventFn
    【异步捕获】异步操作必须捕获错误+输出+处理或抛出 try / catch 使用await的区域
    【必须适配当前项目风格】本指南仅供参考，你的代码风格以当前项目（不是当前文件）90%的代码风格为标准准靠拢
  ----
